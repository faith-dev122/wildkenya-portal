# Week 5 - Database CRUD Operations and Admin Panel

## What was done this week
- Built full admin panel with dark sidebar navigation
- Implemented CREATE operation - Add New Park and Add New Animal forms
- Implemented READ operation - dynamic listing of all parks and animals
- Implemented UPDATE operation - Edit Park and Edit Animal forms
- Implemented DELETE operation - delete with confirmation popup
- Built parks listing page with search and region filter
- Built animals listing page with conservation status filter
- Built park detail page with wildlife list and reviews system
- Built animal detail page with conservation status scale
- Implemented SQL JOINs to display related data across tables
