# Week 8 - Responsive Web Design and Mobile-First Development

## What was done this week
- Updated style.css with Mobile-First base styles
- Added CSS media query breakpoints at 768px and 1024px
- Created a custom CSS Grid class called parks-grid for the parks listing page
- Parks grid displays 1 column on mobile, 2 columns on tablet, 3 columns on desktop
- Added Flexbox layout for the profile page and hero section buttons
- Added responsive image styles using max-width 100% and height auto
- Tested the website on mobile, tablet and desktop screen sizes using Chrome DevTools

## Files updated this week
- assets/css/style.css - added Mobile-First styles, media queries, CSS Grid and Flexbox
- pages/parks.php - updated to use the custom parks-grid CSS Grid class

## Technologies used
- CSS3 Media Queries
- CSS Grid
- Flexbox
- Mobile-First Design
- Responsive Images
- Chrome DevTools for testing

## Breakpoints used
- Mobile: 0px to 767px - 1 column layout
- Tablet: 768px and above - 2 column layout
- Desktop: 1024px and above - 3 column layout
